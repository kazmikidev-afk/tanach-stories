סיפורי התנ"ך - אדם v1.18.0

מורידים את כל קובצי ה-ZIP מהתיקייה למחשב ומחלצים כל אחד בנפרד.
לא מעלים את ה-ZIP עצמו.

לכל קובץ לפי הסדר:
1. פותחים https://github.com/kazmikidev-afk/tanach-stories בענף main.
2. בוחרים Add file > Upload files.
3. גוררים את התוכן מתוך התיקייה שחולצה, לא את התיקייה העוטפת:
   בסבבי האודיו: רק את התיקייה audio.
   בסבב האחרון: audio, index.html, THIRD_PARTY_NOTICES.txt.
4. ממתינים לסיום ובודקים נתיבים כמו audio/adam/1-1.mp3, בלי שם התיקייה העוטפת.
5. כותבים הודעת commit קצרה, למשל Add Adam audio batch 1.
6. בוחרים Commit directly to the main branch ולוחצים Commit changes.
7. חוזרים לשורש הריפו ועוברים לקובץ הבא.

את קובץ app-and-metadata מעלים אחרון, אחרי כל האודיו.
לא מעלים את README-HE.txt או SHA256SUMS.txt; אלה הוראות ורשימת בדיקה בלבד.
אם index.html השתנה מאז הכנת החבילה, עוצרים לפני הסבב האחרון ומעדכנים אותי.
בסיום שולחים לי הודעה כדי שאבדוק את הפרסום וההקראה באתר.

86 סיפורים + דוגמת קול, 86 קובצי תזמון JSON. אין צורך ב-Gemini להקראת סיפורים.
סיפורי התנ"ך ורש"י המוצגים לא שונו. הגייה אינה מובטחת בכל מילה.
בהשמעה ראשונה צריך חיבור. השמירה היא במכשיר הזה בלבד ועלולה להימחק.
